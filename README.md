# 🛍️ Love Store E-commerce

Proyecto E-commerce desarrollado con **React.js**, enfocado en la creación de una tienda online moderna, dinámica y responsiva.
La aplicación permite explorar productos, realizar búsquedas en tiempo real, gestionar un carrito de compras y simular un proceso de checkout, aplicando buenas prácticas de desarrollo frontend y arquitectura basada en componentes.

# 🚀 Características Principales

* ✅ Galería dinámica de productos
* ✅ Buscador de productos en tiempo real
* ✅ Carrito de compras funcional
* ✅ Gestión de cantidades y total de compra
* ✅ Navegación SPA con React Router
* ✅ Diseño responsivo para móvil, tablet y desktop
* ✅ Componentización reutilizable
* ✅ Persistencia de datos con localStorage
* ✅ Interfaz moderna y atractiva
* ✅ Simulación de checkout

# ⚙️ Instalación del Proyecto

## 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/Heruse22/Proyecto_Love-Store_E-commerce.git
```

## 2️⃣ Entrar al proyecto

```bash
cd Proyecto_Love-Store_E-commerce
```

## 3️⃣ Instalar dependencias

```bash
npm install
```

## 4️⃣ Ejecutar el proyecto

```bash
npm run dev
```
